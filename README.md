# Reamlet extension

Browser extension that opens PDFs in [Reamlet](https://github.com/nicholasHespe/Reamlet), a standalone PDF viewer. Reamlet needs to be installed for the extension to work.

## Requirements

- Chrome 128 or newer, or another Chromium-based browser (Edge, Brave, …) built on Chromium 128 or newer
- [Reamlet](https://github.com/nicholasHespe/Reamlet)

## Install

Load the `extension` folder as an unpacked extension. Chrome's guide to [loading an unpacked extension](https://developer.chrome.com/docs/extensions/get-started/tutorial/hello-world) covers it, and the same steps work in other Chromium-based browsers.
